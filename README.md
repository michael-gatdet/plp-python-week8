# My Personal Mini-Toolkit

## Project Description
My Personal Mini-Toolkit is a simple Python program that provides three useful tools through one main menu.

## Features

1. **Simple Calculator:** Performs addition, subtraction, multiplication, and division.
2. **To-Do List Manager:** Allows users to add, view, and remove tasks.
3. **Number Guessing Game:** Allows users to guess a random number between 1 and 10.

## How to Run the Program

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run this command:

```bash
python toolkit.py
```

5. Choose a tool by entering its menu number.

## Project Files

- `toolkit.py` – Main Python program.
- `toolkit_plan.txt` – Project plan.
